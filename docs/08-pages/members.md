# Members

**Sidebar item on league home. Visible to everyone, including spectators.**

A plain roster: **name · team name · admin badge** where applicable.

**No points or rank** — those belong on the leaderboard. Members answers "who is
in this league", not "who is winning".

> Distinct from the member list inside **Admin Center**, which carries the
> administrative actions — make and remove admin, ban — and is admin-only. Same
> people, different capabilities.
